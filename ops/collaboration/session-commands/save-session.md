把本次 session 的工作进展保存为存档文件。

## 流程

1. 回顾本次 session 做了什么（改了哪些文件、讨论了什么、解决了什么问题）
2. 在 `.claude/sessions/` 下创建存档文件，文件名格式：`YYYY-MM-DD-简短描述.md`
3. 按下面的模板填写每个部分，**不要跳过任何部分**，没有内容就写"无"
4. 写完后展示给用户确认，用户说 OK 后结束

## 存档模板

```markdown
# Session: YYYY-MM-DD

**项目:** [项目名]
**主题:** [一句话说清楚这次干了什么]

---

## 目标
[这次 session 要完成什么，写清楚让一个完全不知情的人也能看懂]

## 已完成（附证据）
[只列确认做好的东西，每条附上怎么确认的——测试通过了 / 页面能打开 / API 返回正常]
- **[做好的事]** — 证据: [怎么确认的]

## 试了没成功（附原因）
[最重要的部分！每条写清楚具体报什么错、为什么不行，防止下次重复踩坑]
- **[试过的方案]** — 失败原因: [具体报错信息或原因]

## 还没试的方案
[想到了但还没做的思路]

## 文件状态

| 文件 | 状态 | 说明 |
|------|------|------|
| `path/to/file` | 已完成 / 进行中 / 未开始 | 简要说明 |

## 做了什么决定
[选了什么方案、放弃了什么方案、为什么]
- **[决定]** — 原因: [为什么这么选]

## 卡住的地方
[还没解决的问题、等待的依赖]

## 下一步
[精确到可以直接动手的下一步操作，不需要再思考从哪开始]
```

## 注意事项

- "试了没成功"是最重要的部分，写得越具体越好，要包含具体的报错信息——它是跨会话防重复踩坑的核心
- 每次创建新文件，不要追加到旧文件
- 文件名用英文，简短描述用 2-3 个词概括主题，例如 `2026-04-03-login-fix.md`
