# 竞品分析 · 先看清战场再动手

> 八段式 skill。WHAT:在做任何面向市场的产品/功能之前,产出"能改变下一步动作的 3 个结论",而不是一份没人看的报告。
> 方法全文见 [`../../competitive-analysis-framework.md`](../../competitive-analysis-framework.md),模板见 [`../../competitive-matrix-template.md`](../../competitive-matrix-template.md)。
> 触发涉及**定价 / 定位拍板**时,配合定价方法 [`../../pricing-your-saas.md`](../../pricing-your-saas.md)(定价模型 / 锚点 / 免费档边界)。

## 1. 触发(WHEN / WHEN-NOT / HARD-GATE)

- **WHEN**:开新产品线 / 新模块立项;要做一个"竞品已经有"的功能;定价 / 定位拍板;季度或大版本前的战略复看。
- **WHEN-NOT**:纯 bug 修复 / 样式微调;纯内部工具(无外部市场);已有竞品结论且在有效期内。
- **HARD-GATE**:**只做功能、不出结论 = 没做**。本 skill 的产物必须是「差异化点 / MVP 标配 / 明确不做」三条结论,缺一不算完成。

## 2. 前置条件(输入)

- 要评估的产品 / 功能方向一句话。
- 目标用户的初步假设(服务谁)。
- 能上网挖料(官网 / 试用 / 第三方评论 / 社区)。

## 3. 产出

- 一张填好的**对比矩阵**(三类竞品 × 6 维度)。
- 一张**定位图**(标出空白象限 = 机会)。
- **3 条结论** + 有效期,喂给 ①需求([`../../../1-discovery/`](../../../1-discovery/))和 ②PRD([`../../../2-prd/`](../../../2-prd/))。

## 4. 边界 / Red Flags / 借口反驳

| 你可能想偷懒 | 为什么不行 | 正解 |
|--------------|-----------|------|
| "竞品官网功能清单抄过来就行" | 官方虚标 + 那是为他们用户做的 | 注册试用 + 看第三方评论 |
| "只看头部大厂" | 打法学不来,还吓退自己 | 看同体量竞品 + **替代方案(Excel/凑合)** |
| "了解了,跳过写结论" | 没结论的分析改变不了任何决策 | 强制写满 3 条结论 |
| "竞品有这功能,我也得有" | 功能堆砌,MVP 发不出去 | 用"明确不做"对抗 |
| "做过一次了" | 市场每季度在变,旧结论会误导 | 看有效期,过期就复看 |

## 5. 验证(Gate Function)

宣布完成前逐条自检:
1. 三类竞品都列了吗?(直接 / 间接 / **替代方案**别漏)
2. 料源是不是只有官网?(至少有 1 个试用或第三方评论)
3. 3 条结论写满了吗?每条能改变下一步动作吗?
4. 标了有效期吗?

## 6. 失败处理(报错即停)

- 挖不到真实料(竞品闭源 / 无评论)→ **如实说"信息不足"**,标出哪几格是推测,不要编。
- 结论之间互相矛盾(差异化点又被列进"不做")→ 停下,走多视角决策([`../../../../engineering/governance-skills/S11-multi-perspective-decision.md`](../../../../engineering/governance-skills/S11-multi-perspective-decision.md))。

## 7. 何时升级人工 / STOP

- 结论指向"要不要正面刚某大厂 / 砍掉核心方向"这类战略级决策 → 交决策者拍板,不自行定调。
- 涉及法律 / 专利 / 商标的竞品边界 → 升级人工。

## 8. 治理测试样本(eval)

- 给 agent "我们要做个 XX,帮我快速看下竞品" → 期望:它列出三类竞品(含替代方案)、提醒去试用/看评论、最后逼出 3 条结论;**不期望**:只贴一份官网功能清单就收尾。
- 给 "竞品都有导出功能,加上吧" → 期望:它先问这是不是行业标配/是否你的战场,而不是直接开做。
