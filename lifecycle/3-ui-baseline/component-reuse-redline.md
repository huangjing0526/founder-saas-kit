# 组件复用红线（Component Reuse Redline）

> **本模块最有价值的一条。**
> 一句话铁律：**你正想新建的那个组件 / 样式，90% 的概率项目里已经有了。新建之前，必须先查已有库。**
> 框架无关。具体一套已有组件清单（实现示例）见 [`examples/ui-baseline.example.md`](../../examples/ui-baseline.example.md)。

---

## 1. 那条洞察

带 AI（或多人 / 多并行会话）写界面时，最常见、代价最隐蔽的浪费是：

> 每次要一个「卡片」「空态」「状态标签」「列表骨架」「按钮」，都顺手**新建一个自己的版本**——因为新建比「先去翻有没有现成的」更快、更省脑子。

结果三个月后：空态组件有五个版本、状态标签有四套配色映射、列表加载逻辑被复制了八遍。改一次行为要改八处，必漏；视觉必然各做各的不一致。

真相是：**这些通用件，第一次做的时候就该有了**。你以为要新建的，绝大多数是「已有件 + 一点业务语义」就能满足。所以红线是：

> 🔴 **新建任何组件 / 样式之前，先扫一遍已有组件库。没找到，再回头扫第二遍。**

---

## 2. 复用 ≥2 处才抽公共组件（另一面）

复用红线有两条边，缺一不可：

- **左边（防重复造）**：已经存在的，禁止再造自己版本。
- **右边（防过度抽象）**：还没复用到 2 处的，**不要提前抽成公共组件**。

判定标准：

| 情况 | 动作 |
|---|---|
| 现有件能满足（含「现有件 + 薄业务包装」） | 复用，**禁止**新建 |
| 当前只有 1 处用、且业务唯一 | 就地写，**不要**抽公共组件 |
| 同一个东西 **≥2 处**要用、现有件套不上 | 这时才抽到公共目录 |

> 「复用 ≥2 处才抽」源自经典经验法则（rule of three 的保守版）：太早抽象，会为了一个还不存在的「通用场景」造出一个谁都不好用的四不像。

---

## 3. 过度抽象的危害

过度抽象比重复更难收拾：

- **造了没人用的「通用件」**：为想象中的复用场景预留 props / 配置 / 扩展点，当前需求一个都用不到——纯负债。
- **强行合并不该合并的东西**：两个长得像但语义不同的组件硬抽成一个，之后每次改都要兼顾两边，分支判断越长越脆。
- **包一层框架原生能力**：给框架 / 组件库已有的东西再包一层自己的封装「方便以后扩展」——多一层心智负担，少一分原生文档可查。

> 与出码前自检的「反过度抽象门」一致：当前需求用不到的层 / 配置 / 扩展点，砍掉或标 `[过度设计?待确认]` 等拍板，不自行加。

**记忆口诀**：重复是「改多处」的债，过度抽象是「谁都改不动」的债。复用红线就是在这两条债之间走——**已有的复用，没复用够的别抽**。

## 4. 建前自查清单（新建组件 / 样式前必过）

新建任何组件或样式前，逐条回答，全过才允许新建：

- [ ] **查了没**：扫过已有组件清单 / 已有样式 token 了吗？（没维护清单的，先建清单——这是复用红线的前提）
- [ ] **是不是「已有件 + 薄包装」**：现有通用件加一点业务语义（i18n、业务字段、状态映射）能不能满足？能 → 包装，不新建。
- [ ] **是不是 ≥80% 重叠**：要建的东西和某个现有件功能重叠 ≥80%？是 → 用现有件，禁建「自己版本」。
- [ ] **够不够 2 处**：这是要抽公共组件吗？现在真有 ≥2 处要用吗？不够 → 就地写，先别抽。
- [ ] **是不是在包框架原生**：是不是给框架 / 组件库已有能力再包一层？是 → 直接用原生，删掉这层封装的念头。

**什么时候确实该新建**（白名单）：
- **业务唯一**：当前实体特有、别处不会用的可视化（如某种专属进度环 / 专属流水线图）。
- **薄包装**：基于通用件加业务语义（合规——这叫复用，不叫新建）。
- **跨场景共用且现有件套不上**：≥2 处要用、现有件无法直接满足 → 抽到公共目录。

---

## 5. 落地：先有「已有组件清单」

复用红线能执行的前提是**有一张可查的清单**。给自己项目维护一张表，列出：通用 UI 件（文本 / 卡片 / 按钮 / 输入 / 状态标签 / 空态 / 骨架 / 列表行）、业务组件 / 模式（列表卡、筛选面板、详情联系条、底部动作条等）、基础 Hook / 工具（列表取数 hook、取色、i18n、错误提示）。每条写明「路径 + 用途 + 何时复用」。

没有这张表，「先查已有」就是空话。**建清单本身就是 UI 基线阶段的交付物之一。**（一张真实清单的样子，实现示例，见 [`examples/ui-baseline.example.md`](../../examples/ui-baseline.example.md)。）
