# 竞品分析方法

> 目的不是"做一份漂亮的竞品报告",是**得出 3 个能改变你下一步动作的结论**。
> 没有结论的竞品分析 = 浪费时间。

---

## 第 1 步:列出竞品(三类,别只看直接竞品)

| 类型 | 定义 | 例子(以"给中小企业做的 CRM"为例) | 为什么要看 |
|------|------|-----------------------------------|-----------|
| **直接竞品** | 同样的事、同样的人群 | 其他中小企业 CRM | 正面对比功能/定价 |
| **间接竞品** | 不同的事、同样的人群 / 同样的事、不同人群 | 大厂 CRM 的廉价版、通用项目管理工具 | 看他们怎么"顺手"抢你的用户 |
| **替代方案** | 用户现在到底用什么凑合 | Excel 表格、微信群 + 记事本、纸质本 | **最容易被忽略,却往往是你真正的对手**——用户不是在你和竞品之间选,是在你和"继续用 Excel"之间选 |

> 🔑 **替代方案最危险**:一个新产品最常见的死因不是输给竞品,是用户觉得"现在这样也还行"。把"用户现在怎么凑合"列进来。

## 第 2 步:每个竞品看什么(6 个维度)

1. **目标用户**——他们到底服务谁?(规模/行业/角色)和你重叠多少?
2. **核心功能**——他们的"招牌菜"是什么?哪些是行业标配、哪些是他们的差异化?
3. **定价**——多少钱、怎么收(按人/按用量/一次性)、免费档给到哪?
4. **定位与话术**——官网首页一句话怎么说自己?在卖什么"感觉"?
5. **优劣势**——用户夸什么、骂什么?(看真实评论,不是看他们自己说的)
6. **护城河**——他们靠什么留住用户?(数据迁移成本、生态、网络效应)难不难被绕过?

## 第 3 步:多渠道挖料(别只看官网)

| 渠道 | 看什么 | 真实度 |
|------|--------|--------|
| 官网 / 定价页 | 功能清单、定价、定位话术 | ⚠️ 官方美化,功能清单常虚标 |
| **注册试用 / 看 demo** | 真实体验、藏起来的限制 | ✅ 最真,值得花 1 小时 |
| **第三方评论**(应用商店 / G2 / Capterra / 小红书 / 知乎 / Reddit) | 用户真实夸什么骂什么 | ✅ 骂点 = 你的机会 |
| 社媒 / 社区 | 用户问什么、抱怨什么 | ✅ 高信号 |
| 招聘 JD / 融资新闻 | 他们要往哪打(招什么岗 = 押注什么方向) | ✅ 战略信号 |
| 变更日志 / 路线图 | 他们最近在做什么、节奏多快 | ✅ 看趋势 |

## 第 4 步:填矩阵 + 找缺口

把第 2 步的维度填进 [`competitive-matrix-template.md`](competitive-matrix-template.md) 的对比矩阵,然后问:

- **哪一列大家都弱?** → 可能是你的差异化切入点。
- **哪一类用户没人好好服务?** → 细分机会。
- **哪些功能人人都有?** → 行业标配,你的 MVP 大概率躲不掉(但要做到 80 分,不必做到 120)。

## 第 5 步:得出 3 个结论(这一步才是重点)

强制自己写出三句话,每句都能改变下一步动作:

1. **我们的差异化点是:______**(竞品都没做好的那一件事)
2. **MVP 必须有的行业标配:______**(不做用户根本不会考虑你)
3. **明确不做:______**(竞品做了,但不是我们的战场——写进 PRD 范围)

> 把这 3 条喂给 ①需求发现([`../1-discovery/`](../1-discovery/))和 ②PRD([`../2-prd/`](../2-prd/))。

## 反模式(踩了就白做)

| 反模式 | 为什么错 | 怎么做 |
|--------|---------|--------|
| **抄竞品功能清单当需求** | 他们的功能是为他们的用户做的,不是你的;照抄 = 做成四不像 | 看缺口和差异化,不是看清单 |
| **只看大厂** | 大厂的打法你学不来(资源不对等),还会吓退自己 | 重点看和你体量相近的、以及"替代方案" |
| **只看功能,不看定位和定价** | 同样的功能,定位/定价不同就是不同的产品 | 6 个维度都要看 |
| **一次做完就不更新** | 市场每季度都在变,旧结论会误导决策 | 每季度 / 大版本前快速复看(标好"何时复看") |
| **竞品有我也要有** | 功能堆砌,MVP 永远发不出去 | 用第 5 步的"明确不做"对抗 |
| **拿官网话术当真相** | 官方美化 + 虚标功能 | 以试用 + 第三方评论为准 |
