# session-commands/ — 会话记忆三件套

跨会话的「记忆」机制:把当前进展写成存档文件,下一个会话(或明天的你)能直接 resume,不用重新讲一遍上下文。三个命令配套使用。

| 命令 | 什么时候用 | 干什么 |
|---|---|---|
| [`save-session.md`](save-session.md) | **收工时** | 把本次进展、已完成 / 进行中 / **试了没成功** 写成一份存档 |
| [`resume-session.md`](resume-session.md) | **开工时** | 读最近的存档,恢复上下文后等你指示,不自动开干 |
| [`clean-sessions.md`](clean-sessions.md) | 存档攒多了 | 清理过期存档,避免噪音 |

> 关键价值在 save 里那段 **「试了没成功」** ——记下具体报什么错、为什么不行,防止下个会话重复踩同一个坑(呼应防漂移与 S7 系统化调试)。
