清理过期的 session 存档。

## 流程

1. 列出 `.claude/sessions/` 下所有存档文件，按日期排序
2. 标记超过 30 天的为"待删除"
3. 展示完整列表，标明哪些要删、哪些保留
4. **等用户确认后再删除**，不要自动删

## 输出格式

```
Session 存档清理
════════════════

保留（30 天内）:
  2026-04-03-login-fix.md        (今天)
  2026-03-28-dashboard-api.md    (6 天前)

待删除（超过 30 天）:
  2026-02-15-init-setup.md       (47 天前)
  2026-02-10-prisma-migration.md (52 天前)

确认删除 2 个过期存档？
```
