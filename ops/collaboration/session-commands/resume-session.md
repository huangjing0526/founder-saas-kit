读取最近的 session 存档，恢复上下文后等待用户指示。

## 流程

1. 查找 `.claude/sessions/` 下最新的存档文件（按修改时间排序）
2. 如果用户指定了日期或文件名，找对应的文件
3. 读取完整内容
4. 用下面的格式输出摘要
5. **不要自动开始工作**，等用户说做什么

## 输出格式

```
已加载: [文件路径]
════════════════════════════

项目: [项目名]
主题: [主题]

目标:
[2-3 句话概括]

当前状态:
  已完成: [数量] 项
  进行中: [列出文件]
  未开始: [列出文件]

不要重试的方案:
  [列出每个失败方案和原因——这条最重要，优先级最高]

卡住的地方:
  [列出阻塞项]

下一步:
  [存档里定义的下一步]

════════════════════════════
准备好了，你要做什么？
```

> "不要重试的方案"放在最显眼位置且优先级最高：恢复上下文后，AI 必须先把存档里"试了没成功"的方案当成硬约束，**绝不重复尝试已经失败过的路径**，除非用户明确要求重试。

## 异常处理

- 没找到存档文件 → 告诉用户"没有找到存档，可以用 /save-session 创建"
- 存档里提到的文件已不存在 → 在摘要里标注"⚠️ 文件已不存在"
- 存档超过 7 天 → 提醒"这份存档已经 N 天了，代码可能已有变动"

## 参数

$ARGUMENTS — 可选，可以是日期（如 `2026-04-03`）或完整文件路径
